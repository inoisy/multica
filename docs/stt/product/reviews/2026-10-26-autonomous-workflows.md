У Девопса удалена живая инструкция `conveyor result`, восстановлен `workflow-step`.
- Workflow `81777ee1-8f61-4cf0-b3af-243024777b6f`: «Multica — стадии, проверка и штатная доставка». Вместо всех отключённых обработчиков назначены исполнители. Backend-стадии — `in_progress → done`, web — `started_2 → done`; это передача кода. Общая QA/review — STT-450. Обычный backend — `dev → qa → review → merge` (Девопс). Координатор parent — Техдиректор в `analysis`, ожидание стадии — одна condition, `waiting`.
- Workflow `fbb97b64-879c-47d0-b11f-9d415a42fc75`: «РП — разработка, приёмка и доставка». `in_progress` у Девопса продолжает STT-453 до полного перехода и доставки. Действующий локальный accept сохраняется до готового CI accept STT-429 и проверенного переключения; готовый локальный merge не завершает всю миграцию.

Формат root-передачи: причина, принятый SHA/PR, точные команды и ожидаемый результат, health, откат и сохранённый шаг/исполнитель. Ответ автора будит назначенного продолжателя одним событием, без второго назначения или повторного рана того же перехода.

Модели, runtime, пулы, секреты, invocation permissions и concurrency не менялись. Источник шести промптов и JSON определений сохранён в `inoisy/stt-agents`, ветка `t-12345-autonomous-delivery`, каталог `workflows/autonomous-2026-10-26/` содержит порядок применения/проверки/отката. Старые live-подсказки по harness не перенесены поверх уже исправленного источника.

## Экономия и условия релиза

Один писатель общих файлов и один координатор; существующие PR и результаты сохраняются. Один статусный переход запускает следующего исполнителя, упоминание/назначение/wakeup к нему не добавляется. Проверки одного SHA и условий переиспользуются. Внешнее ожидание — одно поддерживаемое событие/условие; периодические модельные опросы и повтор неизменного отказа запрещены. Для РП без серверной ссылки PR пока создан один отложенный wakeup на результат CI, это ещё не доказательство готовой механической интеграции — она остаётся частью STT-429/453.

Обычные PR форка — автослияние по обязательному CI, РП Free — существующий Actions gate по CI и review текущего head. Сфера по-прежнему через MR сливается людьми. Стек STT-433 не вливается до общей QA/review. 616 готовится сейчас, вливать/применять её нельзя раньше 01.11.2026 и проверки копии БД; root-исполнение остаётся ручным. Совместимый релиз 613–615 после полной QA/review не задерживается до даты 616. Завершённая стадия и завершённый релиз явно различаются.
